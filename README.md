# Arunteja — Portfolio Website

This repository contains a simple personal portfolio website that showcases projects, skills, and contact information. It's a lightweight, static site built with plain HTML, CSS, and JavaScript so it can be easily hosted anywhere (GitHub Pages, Netlify, a static web server, or opened locally).

## Demo

## About

The site presents an overview of the owner (Arunteja), a profile picture, and sections for projects, skills, and contact details. It's designed to be minimal and responsive.

## Tools & Technologies

- HTML5 (`index.html`) — page structure
- CSS3 (`style.css`) — styling and responsive layout
- JavaScript (`app.js`) — small interactivity or dynamic behavior
- DP.jpg — profile image used on the site
- Any modern web browser to view the site

## Customization

- Replace `DP.jpg` with your own profile photo (keep the filename or update `index.html` to point to a different file).
- Edit the text in `index.html` to change the name, bio, projects, and contact details.
- Modify `style.css` to change colors, spacing, and layout.

## Contact

Replace the contact placeholders in `index.html` with your real email or social links.
